## My ANSI Terminal Graphics Engine.
A graphics enginre that draws graphics entirely through ANSI escape codes with a suprisingly high framerate.

This is a highly experimental engine I'm tinkering with. Please, forgive any rough edges.
The latest version is under the Version 3.x folder.
## Features:
- Full color
- Mode-7 style effects
- Both pixel scope ant tile-scope coordinates
